# 🔍 Universal Image Forensics

A Python-based AI Image Forensics application that detects image authenticity using mathematical and statistical analysis. The system helps identify manipulated or fake images through image processing techniques.

---

## 📌 Features

- Upload Image
- Image Preprocessing
- Mathematical Analysis
- Statistical Analysis
- Fake Image Detection
- PDF Report Generation
- User-Friendly Interface

---

## 🛠 Technologies Used

- Python
- Flask
- OpenCV
- NumPy
- Matplotlib
- Scikit-Image
- ReportLab
- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/dinesh8353/Universal-Image-Forensics.git
```

2. Install required packages

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```
